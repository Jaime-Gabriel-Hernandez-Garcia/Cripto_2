# Práctica 2: Curvas Elípticas sobre $\mathbb{F}_p$

Aplicación interactiva y minimalista para el estudio, verificación y visualización de Curvas Elípticas en campos finitos $\mathbb{F}_p$.

## Ecuación de Weierstrass Corta
y^2 \equiv x^3 + ax + b \pmod p

## Características
1. **Verificación de No Singularidad**: ^3 + 27b^2 \not\equiv 0 \pmod p$.
2. **Cálculo de Puntos**: Búsqueda para cada  \in \{0, \dots, p-1\}$ y extracción de raíces $.
3. **Métricas**: Orden del grupo $\#E(\mathbb{F}_p)$ con punto al infinito $\mathcal{O}$ y Cota de Hasse.
4. **Plano Discreto**: Gráfico Canvas interactivo en $\mathbb{F}_p \times \mathbb{F}_p$.
